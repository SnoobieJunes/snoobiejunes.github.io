How it is built

One Go program using nothing but the Go standard library. No framework, no package manager, no build tool, and nothing downloaded from the internet to build it. It renders plain HTML out of a handful of JSON files, serves the result itself, and compiles to a single file I copy to the tablet. The look is a small design system I made for this site alone, borrowed from the carbonless triplicate forms that repair shops run on.
